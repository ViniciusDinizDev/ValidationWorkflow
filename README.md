Você faz parte de uma equipe de desenvolvimento Full Stack. A equipe deseja automatizar algumas verificações básicas para garantir que os repositórios estejam organizados corretamente.

Sua tarefa é criar um workflow chamado Validação do Projeto, que execute as seguintes ações:


    Seja acionado automaticamente sempre que ocorrer um push em qualquer branch.


    Utilize uma máquina virtual com ubuntu-latest.


    Faça o checkout do código do repositório.


    Exiba no log o nome do repositório e o usuário que iniciou a execução.


    Verifique se o arquivo README.md existe. Se não existir, o workflow deve falhar.


    Exiba uma mensagem informando que a validação foi concluída.

Simule o cenário de sucesso (tem o arquivo README.md) e o cenário de falha (não tem o arquivo README.md).
